# Lockup

The mark beside the name "Humaine Studio" set in type; the brand's signature in headers and footers.

**Markup.** `<a class="hs-lockup" href="/"><img src="<mark url>" alt=""> Humaine Studio</a>`. The image is decorative (`alt=""`) because the name follows it as text. The consumer provides the link target.

- The name is the wordmark: Fraunces 800 with `--soft` (full softness), letter-spacing −0.02em. Default: 24px mark, 18px name. `hs-lockup--lg`: 44px mark, 32px name, for a cover or a title slide.
- The name is always "Humaine Studio": capital H and S, no "The", never "Humane".
- The mark is the primary Klein file (`assets/Logos/humaine-mark.svg`). Keep `space-2` between mark and name.
- Do not set the name in the sans, in all caps, or in Klein. Nothing else on the page is heavier than the wordmark.
- The curlew (`assets/Logos/humaine-curlew.svg`) is not used in the lockup. It stands alone as an avatar or hero image, at 32px or larger.
