# Lockup

The curlew beside the name "Humaine Studio" set in type; the brand's signature in headers and footers.

**Markup.** `<a class="hs-lockup" href="/"><img src="<curlew url>" alt=""> Humaine Studio</a>`. The image is decorative (`alt=""`) because the name follows it as text. The consumer provides the link target.

- The mark is the curlew (`assets/Logos/humaine-curlew.svg`). Default: 32px curlew, 18px name. `hs-lockup--lg`: 56px curlew, 32px name, for a cover or a title slide. Keep `space-2` between them.
- The name is the wordmark: Fraunces 800 with `--soft` (full softness), letter-spacing −0.02em.
- The name is always "Humaine Studio": capital H and S, no "The", never "Humane".
- Do not set the name in the sans, in all caps, or in Klein. Nothing else on the page is heavier than the wordmark.
