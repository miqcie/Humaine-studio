# Logos

The Mondrian block mark: a framed field split into a large open field, a yellow block, a small colored block and a small open block. It is the same geometry as the favicon in `assets/images/icons/`, measured from the 512px PNG. Only the colors changed.

- `humaine-mark.svg`: primary. Klein blue block. Colors: `mark-line` #0E1230, `mark-field` #FAF6EE, `mark-yellow` #F7B902, `mark-blue` #002FA7.
- `humaine-mark-vermilion.svg`: alternate, for a second voice (a talk, a sticker). `mark-red` #C7301C in place of the blue.

Use rules:
- Fixed colors in both themes. On the Klein Night ground the blue-black frame merges into the background and the colored fields carry the mark. That is intended; there is no inverted file.
- Smallest size 16px. Below 24px use the primary mark only.
- Do not recolor, rotate, add a shadow or round the corners. Do not put text on the mark.
- The name is set in type next to it (see the Lockup component), not drawn into the file.
- The curlew bird drafts and the "Humane Studio" concept image are not part of the system.
