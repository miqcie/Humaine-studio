Five free pairings to replace SID's licensed fonts

SID sets headlines in Sirca, a light lowercase serif, and text in ABC Walter Neue; both are paid licenses. Each pairing below is free on Google Fonts and is set with the same Humaine copy, in the Klein & Linen palette. Pick one by letter.

  • Text clear at 13–17px, plain numerals
  • Mono labels and code
